# سیستم گزارش‌نویسی گفتاردرمانی احسان جاسمی

این سیستم یک ابزار سبک، سریع و بسیار زیبا برای ثبت گزارش جلسات گفتاردرمانی و تولید فایل PDF یا چاپ مستقیم آنهاست.

## ویژگی‌ها:
- **طراحی اختصاصی**: برای کلینیک گفتاردرمانی احسان جاسمی با هدر و فوتر شخصی‌سازی شده.
- **حفظ حریم خصوصی**: هیچ داده‌ای در اینترنت ذخیره نمی‌شود و تمام اطلاعات فقط روی مرورگر شما باقی می‌ماند.
- **بدون نیاز به نصب**: فقط با باز کردن یک فایل HTML در مرورگر اجرا می‌شود.
- **خروجی شیک**: فرمت کاملا تمیز و بدون حاشیه برای چاپ و ارائه به والدین مراجعین.

## نحوه استفاده:
کافیست فایل `index.html` را در مرورگر (مانند کروم یا سافاری گوشی آیفون خود) باز کنید.
پس از پر کردن اطلاعات جلسه، دکمه **چاپ / ذخیره PDF** را بزنید.

*می‌توانید برای دسترسی سریع‌تر، آدرس این صفحه را در صفحه اصلی (Home Screen) گوشی آیفون خود اضافه کنید.*
